人因性危害評估工具（NIOSH RLE / KIM-LHC / KIM-MHO）

依據規格完整實作三大評估工具，於純前端靜態頁面即時計算 LI、CLI、KIM 總分與風險分級，並輸出符合 ErgoToolResult 結構的 JSON 結果。

工具選擇

使用提示
  • 所有計算完全遵循規格，不做簡化。
  • 結果會同步寫入 localStorage 的 ergoResult。
  • 可將多個 NIOSH 任務加入列表，計算複合 CLI。

NIOSH 改良提舉方程式 RWL / LI / CLI

僅適用於雙手舒適站姿、良好環境、提舉速度不過快的情境。依據規格中的乘數計算 RWL 與 LI，並可建構複合 CLI。

複合任務列表

KIM-LHC 抬舉/握持/搬運風險

依據 KIM-LHC 指標累計分數並乘以時間評級，得到總分後依門檻分級（<20、20-49、50-99、≥100）。

KIM-MHO 上肢反覆動作

依照力道評級（左右手取高）、抓握、姿勢、環境與時間評級計算總分，並依四級門檻呈現風險。
