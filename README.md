# 人因性危害評估工具 (NIOSH RLE / KIM-LHC / KIM-MHO)

純前端靜態 SPA，依規格完整實作下列工具：

- **NIOSH 改良提舉方程式**：計算 RWL、LI，並支援多任務複合 CLI（頻率加權且不低於最大 LI）。
- **KIM-LHC**：依時間評級、負重評級、姿勢附加分、不良條件與工作組織累計，乘時間評級得總分並分級。
- **KIM-MHO**：左右手用力取高，合併抓握、姿勢、環境、工作組織與時間評級計算總分並分級。

## 使用方式

1. 直接以瀏覽器開啟 `index.html`，或部署至 GitHub Pages（無後端依賴）。
2. 選擇左側工具後填寫表單，按下計算即可即時計算並顯示風險等級。
3. 結果會以 ErgoToolResult JSON 形式寫入 `localStorage` 的 `ergoResult`，方便後續重用。
4. 在 NIOSH 區塊可重複計算並加入複合任務列表，自動計算頻率加權後的 CLI。

## 檔案結構

- `index.html`：主頁面與區塊。
- `assets/css/styles.css`：介面樣式。
- `assets/js/main.js`：載入工具設定、渲染表單與計算邏輯。
- `tools/*.json`：三個工具的設定檔，完全對應規格數值、乘數、分級門檻與提示。

## 開發者筆記

- 所有計算皆依設定檔規則執行，未做任何簡化或推測。
- 風險分級會優先解析範圍式字串（如 `<20`、`20-49`），其他情形則直接評估條件表達式。
- KIM-MHO 施力評級會根據握持秒數、動作頻率在對應表格取值後相加，再與其他指標合併乘以時間評級。
